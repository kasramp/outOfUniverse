## Back after a long break

It has been a long time since the last post here. The blog went quiet, and the old setup quietly stopped working too: the theme no longer built with current Hugo, and the service that published the site shut down years ago.

So I gave Out of Universe a fresh start.

## What is new

- **A new look.** The blog now uses the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme. It is cleaner, easier to read, and has a dark mode. Use the moon icon next to the title to switch.
- **Archives, tags and categories** are in the top menu, so older posts are easy to find.
- **Social links** now live at the bottom of every page.
- **Automatic publishing.** Every new post is built and published by GitHub Actions as soon as it lands.

All the old posts are still here, at the same addresses.
